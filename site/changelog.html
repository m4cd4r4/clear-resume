Changelog

Releases

Each release in CHANGELOG.md, newest first.

  1. 0.3.2

    • The relay stops when work stalls: it stops after two continued sessions in a row make no new commit, and says so.
    • Outside a git repo only the budget applies.
    • With the relay on, the context nudge tells Claude to end without a handover when the task is finished.

  2. 0.3.1

    • The relay: clear and continue with no keypress.
    • After Claude saves a handover, clear-resume runs /clear when the turn ends and submits the prompt that continues from it.
    • Off by default. Needs Claude Code 2.1.275 or later; an older build ignores it.

  3. 0.3.0

    • Headless runs continue themselves: node plugin/scripts/run.mjs runs claude -p in segments.
    • It needs caps (--max-segments, --total-budget-usd, and the command's own --max-turns and --max-budget-usd).
    • It stops the chain when two continued segments in a row make no new commit.

  4. 0.2.1

    • The nudge has settings in Claude Code.
    • Turn it on and set its size with /plugin configure clear-resume@clear-resume, or in /config in Claude Code 2.1.269 or later.

  5. 0.2.0

    • Write one short handover on purpose, /clear, and that window's fresh session picks it up.
    • Other open windows on the same project only list it.
    • Known limitation: the loop runs on /clear. A session started with --resume or /resume loads nothing.

Source: the CHANGELOG.
