Clear the chat. Keep the work.

A free, open-source Claude Code plugin.Install

A 30-item website build, run 3 times with the relay and 3 times with Claude Code's auto-compaction, on Sonnet 5.5.

Finish

Relay: 3 of 3 builds finished. Auto-compaction: 2 of 3.

One compaction run ended its turn after item 20, with 10 items open. 3 runs per arm is a small sample.

Tokens

One long session used about 1.4x the tokens of either clearing method (n=1).

Cost

Median cost: US$12.54 relay, US$13.03 auto-compaction.

The gap is within run-to-run spread.

Starting context

Median tokens rose with the starting context: 36.9M at 22.1k, 48.5M at 45.9k, 52.7M at 67.9k.

Idle return

Back in a 390k session: US$1.56 cold, US$0.30 with a handover (n=1).

A handover continues from a note and a cold return keeps the whole conversation, so this compares cost only.

Install

Relay on, in your terminal:

claude plugin marketplace add https://github.com/m4cd4r4/clear-resume
claude plugin install clear-resume@clear-resume --config auto_nudge=true --config relay=10

Manual (the default): install, then /clear-resume:handover, /clear, go.

claude plugin install clear-resume@clear-resume

Marketplace, Open VSX, releases.

Every run
Does anything leave my machine?

Handovers are plain text files on your disk, in ~/.clear-resume. Nothing is sent anywhere unless you turn on sync (to your own private git remote) or web mode (for Claude Code on the web). Keep secrets out of them.

What does it need?

Node 18 or later and git. On Windows, Claude Code runs plugin hooks through Git Bash, which comes with Git for Windows.

The relay needs Claude Code 2.1.275 or later and works in a terminal and in the VS Code chat panel.
